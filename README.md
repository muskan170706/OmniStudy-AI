# OmniStudy AI

OmniStudy AI is a modern, multimodal AI-assisted study copilot built with **Next.js 15 (React 19)**, **Tailwind CSS**, and **Lucide React** icons. It provides a clean, responsive dark-mode dashboard tailored for real-time lecture analysis, whiteboard transcription, and intelligent AI tutoring.

## 🚀 Key Features & 3-Column Layout

- **Left Column (Audio Capture)**:
  - Prominent **'Record Lecture'** button with animated waveform audio visualizer and elapsed time tracking.
  - Audio file uploader for local `.mp3`, `.wav`, and `.m4a` files.
  - Interactive **'Live Transcript'** area with word counts and instant clipboard copy.

- **Middle Column (Visual Board)**:
  - **'Upload Whiteboard/Slide'** button supporting classroom chalkboard, whiteboard, or presentation slides.
  - Large display container showing uploaded images with contextual AI tags.
  - Built-in sample whiteboard loader for rapid testing and demonstrations.

- **Right Column (AI Tutor)**:
  - Interactive chat interface with message history showing simulated context-aware reasoning.
  - **'Generate Flashcards'** button with interactive flip-card study carousel.
  - Bottom query input with instant response simulations and quick-prompt chips.

## 🛠️ Getting Started

```bash
# Run the development server
npm run dev

# Build for production
npm run build

# Start production server
npm run start
```

Open [http://localhost:3000](http://localhost:3000) to view the application.
